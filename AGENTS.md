# AGENTS.md

This repo's canonical agent/contributor instructions live in [`CLAUDE.md`](CLAUDE.md). This file exists so other AI tools find the same guidance.

**Stack:** Next.js (App Router) + TypeScript, with Payload 3 running in-app. Postgres via Neon; deployed on Vercel. Charts with Recharts/Chart.js. Thai-language UI, Buddhist-era (พ.ศ.) dates, role-scoped data access, and `AuditLog` on attendance edits.

**Before making changes, read [`CLAUDE.md`](CLAUDE.md) and [`docs/README.md`](docs/README.md).**
