# Project Overview — ระบบครูที่ปรึกษา (Advisor Attendance System)

> ระบบเช็คชื่อนักเรียนสำหรับครูที่ปรึกษา โรงเรียนโนนหันวิทยายน (อบจ.ขอนแก่น) — เป้าหมาย ขอบเขต และสรุปเฟสการพัฒนา

## Goal (เป้าหมาย)

ระบบเว็บสำหรับครูที่ปรึกษา (homeroom advisors) ใช้เช็คชื่อและจัดการการมาเรียนของนักเรียนรายวัน พร้อมรายงาน สถิติ และกราฟสำหรับครูและผู้บริหาร

- UI ภาษาไทยทั้งหมด
- แสดงวันที่เป็นปีพุทธศักราช (พ.ศ.) พร้อมชื่อเดือนภาษาไทย
- สอดคล้องกับปฏิทินการศึกษาไทย (2 ภาคเรียน)

## Client (ผู้ใช้งาน / ลูกค้า)

- **โรงเรียน:** โรงเรียนโนนหันวิทยายน (Non Han Wittayayon School)
- **สังกัด:** องค์การบริหารส่วนจังหวัดขอนแก่น (Khon Kaen PAO / อบจ.ขอนแก่น)

## Scope (ขอบเขต)

- เช็คชื่อรายวันในห้องเรียนของครูที่ปรึกษา (มา / สาย / ลา / ขาด)
- แก้ไขและเช็คชื่อย้อนหลัง พร้อมบันทึกการเปลี่ยนแปลง (AuditLog)
- รายงานรายห้อง รายบุคคล และรายชื่อนักเรียนมาสาย
- สถิติรายบุคคล พร้อมธงเสี่ยง (at-risk) และกราฟแสดงแนวโน้ม
- จัดการข้อมูลหลัก: ปีการศึกษา ภาคเรียน ห้องเรียน ครู นักเรียน
- ส่งออกรายงานเป็น Excel และ PDF (ฟอนต์ไทย + โลโก้โรงเรียน)
- ควบคุมสิทธิ์การเข้าถึงตามบทบาท (ครูที่ปรึกษาเห็นเฉพาะห้องของตน)

## Phase summary (สรุปเฟสการพัฒนา)

| Phase | ชื่อ | สาระสำคัญ |
|-------|------|-----------|
| Phase 0 | Setup | Next.js + Payload 3 + Neon บน Vercel; auth; roles; layout ไทย |
| Phase 1 | Master data | ปีการศึกษา/ภาคเรียน ห้อง นักเรียน ครู มอบหมายที่ปรึกษา; CSV import |
| Phase 2 | Core attendance | เช็คชื่อวันนี้ / แก้ไข / ย้อนหลัง + AuditLog |
| Phase 3 | Reports | รายงานรายห้อง นักเรียนมาสาย รายงานนักเรียน + export PDF/Excel |
| Phase 4 | Stats & graphs | สถิติรายบุคคล ธงเสี่ยง แดชบอร์ดกราฟ |
| Phase 5 | Account & polish | เปลี่ยนรหัสผ่าน locale ไทย print styling โลโก้ QA |
