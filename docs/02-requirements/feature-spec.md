# Feature Spec — Button → Feature Mapping (สเปกฟีเจอร์จากหน้าแรก)

> การแมปปุ่มบนหน้าจอหลัก (home screen) ไปยังฟีเจอร์ของระบบ

## Button → feature (ปุ่ม → ฟีเจอร์)

| Button | Feature |
|--------|---------|
| 📌 **เช็คชื่อ** | เช็คชื่อประจำวันของห้องครูที่ปรึกษา: แสดงรายชื่อนักเรียน, เลือกสถานะต่อคนแบบ one-tap, ปุ่ม "มาทั้งหมด" (bulk mark all present), บันทึก |
| ✏️ **แก้ไขเช็คชื่อ** | แก้ไขบันทึกที่บันทึกไว้แล้วของวันที่เลือก (เขียนลง AuditLog) |
| 📝 **เช็คชื่อย้อนหลัง** | เช็คชื่อสำหรับวันที่ย้อนหลัง (ติดธง backdated ใน AuditLog) |
| 📝 **นักเรียนมาสาย** | รายการ/รายงานนักเรียนมาสายตามช่วงวันที่และห้อง พร้อมจำนวนนับ |
| 📄 **รายงานรายห้อง** | สรุปรายห้อง: จำนวนมา/ขาด/สาย/ลา รายวัน ตามช่วงวันที่ ส่งออกได้ |
| 📝 **รายงานนักเรียน** | รายงานรายบุคคลสำหรับพิมพ์ (ผู้ปกครอง/ปกครอง) พร้อมหัวกระดาษและโลโก้โรงเรียน |
| 📊 **สถิตินักเรียน** | สถิติรายบุคคล: % การมาเรียน, จำนวนนับตามสถานะ, ธงเสี่ยง (at-risk flag) กรณีขาดสูง |
| 📈 **กราฟ** | กราฟ: แนวโน้มการมาเรียนรายวัน (line), สัดส่วนตามสถานะ (bar/pie), เปรียบเทียบระหว่างห้อง |
| ✏️ **เปลี่ยนรหัสผ่าน** | เปลี่ยนรหัสผ่านด้วยตนเอง (self-service) |
| 🚪 **Logout** | ออกจากระบบ (session logout) |

## Notes

- สถานะการเช็คชื่อ: **มา** (present) / **สาย** (late) / **ลา** (leave) / **ขาด** (absent)
- ปุ่มที่เกี่ยวกับรายงานและส่งออกดูรายละเอียดที่ [05-reports-exports/reports-spec.md](../05-reports-exports/reports-spec.md)
- การควบคุมสิทธิ์ว่าใครเห็นปุ่มใดดูที่ [user-roles.md](user-roles.md)
