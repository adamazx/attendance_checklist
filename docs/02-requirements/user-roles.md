# User Roles & Access Matrix (บทบาทผู้ใช้และสิทธิ์การเข้าถึง)

> นิยามบทบาทผู้ใช้งานทั้งหมดและเมทริกซ์สิทธิ์การเข้าถึงข้อมูล

## Roles (บทบาท)

| Role | Scope (ขอบเขต) | Can do (ทำได้) |
|------|----------------|----------------|
| **Admin / Academic (วิชาการ)** | ทั้งโรงเรียน | จัดการปีการศึกษา ห้องเรียน นักเรียน ครู; มอบหมายครูที่ปรึกษา; ดูรายงานทั้งหมด |
| **Advisor (ครูที่ปรึกษา)** | เฉพาะห้องที่ได้รับมอบหมาย | เช็คชื่อ / แก้ไข / เช็คชื่อย้อนหลัง; ดูรายงานและสถิติเฉพาะห้องของตน |
| **Discipline / Director (ปกครอง/ผู้บริหาร)** *(optional)* | ทั้งโรงเรียน (อ่านอย่างเดียว) | ดูรายงานทั้งหมด รายชื่อนักเรียนมาสาย ส่งออกข้อมูล |
| **Student / Parent (Phase 2)** | เฉพาะข้อมูลของตน | ดูข้อมูลการมาเรียนของตนเอง |

## Access scoping (การจำกัดสิทธิ์)

- ข้อมูลการเช็คชื่อทั้งหมดถูกจำกัดตามห้องเรียนของครูที่ปรึกษา (classroom-scoped)
- การมองเห็นข้ามห้องทำได้เฉพาะ Admin และ Discipline เท่านั้น
- บังคับใช้ผ่าน access-control functions ของ Payload โดยจำกัด query ด้วยเงื่อนไข `advisor === currentUser`

## Access matrix (เมทริกซ์สิทธิ์)

| Action | Admin | Advisor (own class) | Discipline | Student/Parent |
|--------|:-----:|:-------------------:|:----------:|:--------------:|
| จัดการปีการศึกษา/ภาคเรียน | ✅ | ❌ | ❌ | ❌ |
| จัดการห้อง/นักเรียน/ครู | ✅ | ❌ | ❌ | ❌ |
| มอบหมายครูที่ปรึกษา | ✅ | ❌ | ❌ | ❌ |
| เช็คชื่อ / แก้ไข / ย้อนหลัง | ✅ | ✅ (ห้องตน) | ❌ | ❌ |
| ดูรายงานรายห้อง | ✅ | ✅ (ห้องตน) | ✅ (อ่าน) | ❌ |
| ดูรายงานรายบุคคล | ✅ | ✅ (ห้องตน) | ✅ (อ่าน) | ✅ (ของตน) |
| ส่งออก Excel / PDF | ✅ | ✅ (ห้องตน) | ✅ | ❌ |
| เปลี่ยนรหัสผ่านตนเอง | ✅ | ✅ | ✅ | ✅ |
