# Design System (ระบบการออกแบบ)

> โทนสีแดง–ทอง (red–gold theme) และชุดสีปุ่มการกระทำ (action-button palette)

## Theme tokens (red–gold)

ธีมหลักของโรงเรียน: โทน **แดง–ทอง** สะท้อนสีประจำสถาบัน

| Token | ตัวอย่างค่า | ใช้กับ |
|-------|------------|--------|
| `--color-primary` | แดงเข้ม (deep red) | navbar, ปุ่มหลัก, หัวกระดาษรายงาน |
| `--color-accent` | ทอง (gold) | ขอบ, ไฮไลต์, โลโก้ |
| `--color-bg` | ขาว / ครีมอ่อน | พื้นหลังหน้า |
| `--color-text` | เทาเข้ม / ดำ | ข้อความหลัก |
| `--color-muted` | เทาอ่อน | ข้อความรอง, เส้นคั่น |

> หมายเหตุ: ค่าสีจริง (hex) เป็น stub — ให้กำหนดจากสีประจำโรงเรียนและโลโก้จริงใน [assets/](assets/)

## Action-button palette (ชุดสีปุ่มการกระทำ)

ปุ่มสถานะการเช็คชื่อควรใช้สีสื่อความหมายชัดเจน:

| สถานะ | สี (แนะนำ) |
|-------|-----------|
| มา (present) | เขียว |
| สาย (late) | เหลือง/ส้ม |
| ลา (leave) | ฟ้า |
| ขาด (absent) | แดง |

ปุ่มเมนูหลัก (เช็คชื่อ, รายงาน, สถิติ, กราฟ) ใช้โทนแดง–ทองตามธีม

## Guidelines

- ปุ่ม one-tap ขนาดใหญ่พอสำหรับใช้งานบนมือถือ/แท็บเล็ต
- คอนทราสต์เพียงพอตามหลัก accessibility
- รองรับฟอนต์ไทยที่อ่านง่าย
