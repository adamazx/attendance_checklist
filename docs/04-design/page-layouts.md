# Page Layouts (เค้าโครงหน้า)

> เค้าโครงหน้าแดชบอร์ดหลัก: navbar, hero, logo, grid ปุ่มเมนู, footer

## Home dashboard layout (หน้าแรก)

```
┌─────────────────────────────────────────────┐
│ NAVBAR  [โลโก้]  ระบบครูที่ปรึกษา    [ผู้ใช้ ▼]│
├─────────────────────────────────────────────┤
│                 HERO                          │
│        โลโก้โรงเรียนโนนหันวิทยายน              │
│        ระบบเช็คชื่อนักเรียน                    │
│        ปีการศึกษา 2569 · ภาคเรียนที่ ...       │
├─────────────────────────────────────────────┤
│                 GRID (ปุ่มเมนู)                │
│   [📌 เช็คชื่อ]  [✏️ แก้ไข]  [📝 ย้อนหลัง]      │
│   [📝 มาสาย]    [📄 รายห้อง] [📝 รายงานนักเรียน]│
│   [📊 สถิติ]    [📈 กราฟ]   [✏️ รหัสผ่าน]      │
│   [🚪 Logout]                                 │
├─────────────────────────────────────────────┤
│ FOOTER  โรงเรียนโนนหันวิทยายน · อบจ.ขอนแก่น    │
└─────────────────────────────────────────────┘
```

## Sections (ส่วนประกอบ)

- **Navbar** — โลโก้ + ชื่อระบบ + เมนูผู้ใช้ (เปลี่ยนรหัสผ่าน / ออกจากระบบ)
- **Hero** — โลโก้โรงเรียน ชื่อระบบ และบริบทปีการศึกษา/ภาคเรียนที่ใช้งานอยู่
- **Grid** — ปุ่มเมนูหลักแบบ card grid (ดูการแมปปุ่มที่ [feature-spec.md](../02-requirements/feature-spec.md)) โดยแสดงเฉพาะปุ่มที่บทบาทผู้ใช้มีสิทธิ์
- **Footer** — ชื่อโรงเรียนและสังกัด

## Responsive

- Grid ปรับจำนวนคอลัมน์ตามขนาดหน้าจอ (มือถือ 2 คอลัมน์ / เดสก์ท็อป 3–4 คอลัมน์)
- ปุ่มขนาดใหญ่เหมาะกับการแตะบนแท็บเล็ต
