# Reports & Exports (รายงานและการส่งออก)

> ประเภทรายงาน การส่งออก Excel/PDF (ฟอนต์ไทย, วันที่ พ.ศ.) และข้อกำหนดเฉพาะการศึกษาไทย

## Report types (ประเภทรายงาน)

| รายงาน | เนื้อหา |
|--------|---------|
| **รายงานรายห้อง** (per-class) | สรุปรายวัน: จำนวนมา/ขาด/สาย/ลา ตามช่วงวันที่ ส่งออกได้ |
| **นักเรียนมาสาย** (late students) | รายชื่อนักเรียนมาสายตามช่วงวันที่และห้อง พร้อมจำนวนนับ |
| **รายงานนักเรียน** (per-student) | รายงานรายบุคคลสำหรับพิมพ์ (ผู้ปกครอง/ปกครอง) พร้อมหัวกระดาษและโลโก้โรงเรียน |

## Export (การส่งออก)

- ส่งออกเป็น **Excel (.xlsx)** และ **PDF**
- PDF ฝังฟอนต์ไทย (embedded Thai font) + โลโก้/หัวกระดาษโรงเรียน
- เค้าโครงสำหรับพิมพ์ (printable layouts) ทั้งรายบุคคลและรายห้อง

## Filters (ตัวกรอง)

- ช่วงวันที่ (date range)
- ภาคเรียน (term filter)
- ห้องเรียน (class filter)

## Thai education specifics (ข้อกำหนดเฉพาะการศึกษาไทย)

- แสดงวันที่เป็น **พ.ศ.** พร้อมชื่อเดือนภาษาไทย
- ปฏิทินการศึกษา: 2 ภาคเรียน (พ.ค.–ก.ย. / พ.ย.–มี.ค. โดยประมาณ); ตั้งค่า date picker เริ่มต้นเป็นภาคเรียนที่ใช้งานอยู่
- นำเข้ารายชื่อนักเรียนจาก CSV/Excel (มักมาจากระบบ master เดิม) พร้อม **column mapping + preview**
- เรียงชื่อแบบไทย (Thai sorting) และจัดการคำนำหน้า (เด็กชาย / เด็กหญิง / นาย / นางสาว)
